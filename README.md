# Rabotyaga Main — сайт подписки

Лендинг, оплата криптовалютой через Crypto Bot в Telegram (без KYC и юрлица), выдача ключей, проверка ключей для скрипта и админка.
Next.js 14 (App Router) + Upstash Redis. Рассчитан на Vercel.

## Как это работает

1. Покупатель выбирает тариф на главной, сайт создаёт счёт в Crypto Pay и открывает оплату в Telegram (Crypto Bot).
2. После оплаты сайт узнаёт об этом двумя способами: вебхук `POST /api/webhook/cryptopay` (подпись проверяется) и опрос статуса счёта, пока открыта страница заказа. Достаточно любого из них: заказ помечается оплаченным, создаётся ключ.
3. Страница заказа `/order/<id>` сама обновляется и показывает ключ.
4. Скрипт в игре обращается к `GET /api/check?key=...&hwid=...`. Ответ: `OK|<unix-время окончания>` или `ERR|invalid|expired|hwid|banned`.
5. Срок подписки начинается с первой активации, ключ привязывается к ID компьютера (HWID).

## Запуск на Vercel

1. Залейте папку в репозиторий GitHub (или используйте `vercel` из консоли) и импортируйте проект в Vercel.
2. В проекте: **Storage → Create / Marketplace → Upstash Redis** и подключите к проекту. Переменные `UPSTASH_REDIS_REST_URL` и `UPSTASH_REDIS_REST_TOKEN` (или `KV_REST_API_*`) подставятся сами. Бесплатного тарифа хватит.
3. **Settings → Environment Variables**, задайте:

| Переменная | Что это |
|---|---|
| `CRYPTOPAY_TOKEN` | API Token приложения Crypto Pay (см. ниже) |
| `ADMIN_PASSWORD` | пароль админки |
| `SESSION_SECRET` | длинная случайная строка (32+ символов) |
| `SITE_URL` | адрес сайта с https, без слэша в конце, например `https://rabotyaga.vercel.app` |
| `NEXT_PUBLIC_SUPPORT_URL` | ссылка на поддержку, например `https://t.me/yourname` |
| `NOTIFY_BOT_TOKEN`, `NOTIFY_CHAT_ID` | необязательно: токен Telegram-бота (@BotFather) и ваш chat id. Тогда о новых обращениях в поддержку вы получите сообщение в Telegram |
| `NEXT_PUBLIC_DOWNLOAD_URL` | ссылка на бесплатную версию скрипта (необязательно) |

4. Задеплойте заново (Redeploy), чтобы переменные применились.
5. **Crypto Pay:** откройте в Telegram бота @CryptoBot → **Crypto Pay** → **Create App**, введите название, скопируйте **API Token** в `CRYPTOPAY_TOKEN`.
6. **Вебхук (желательно):** там же **My Apps → ваше приложение → Webhooks → Enable Webhooks**, адрес `https://ВАШ-САЙТ/api/webhook/cryptopay`. Без вебхука сайт всё равно выдаст ключ: он сам проверяет оплату, пока покупатель смотрит страницу заказа. Вебхук нужен на случай, если человек закрыл страницу сразу после оплаты (тогда ключ можно выдать позже кнопкой в админке или он появится при следующем открытии страницы заказа).

## Подключение скрипта

В начале блока `ПОДПИСКА "ПРО"` в скрипте:

```lua
LIC_SERVER = "https://ВАШ-САЙТ/api/check"
LIC_DEV_UNLOCK = false
```

## Проверка перед запуском продаж

1. Откройте `/admin`, создайте ключ на 1 день, вставьте его в скрипте на вкладке «Подписка», нажмите «Активировать». Должно появиться «Подписка активна».
2. Оплатите самый дешёвый тариф реальной небольшой суммой через Crypto Bot и убедитесь, что ключ появился на странице заказа. Если нет, найдите заказ во вкладке «Заказы» и нажмите «Выдать ключ».

## Админка `/admin`

- Создание ключей вручную (для продаж в личке), продление на 30 дней, сброс HWID (если человек сменил компьютер), блокировка, удаление.
- Вкладка «Заказы»: все заказы и ручная выдача ключа, если вебхук не дошёл.

## Где менять тарифы и тексты

- Цены и сроки: `lib/plans.ts`.
- Тексты, список функций и вопросы: `app/page.tsx`.
- Цвета: переменные в начале `app/globals.css`.

## Локальный запуск

```bash
npm install
cp .env.example .env.local   # заполните значения
npm run dev
```

Без Upstash локально данные хранятся в памяти и пропадают при перезапуске. В продакшене без базы сайт намеренно не работает.

## Ограничения и безопасность

- Проверка ключа защищает от обычных пользователей, но не от тех, кто умеет править Lua-код на своём компьютере. Платный код целиком на клиенте не защитить.
- Лимиты запросов: проверка ключа 40 в минуту с одного IP, создание счёта 10 за 10 минут, вход в админку 8 за 15 минут.
- Ссылка на страницу заказа (`/order/<32 символа>`) содержит ключ, она работает как секрет: просите покупателей не публиковать её.
- Пароль админки и `SESSION_SECRET` держите только в переменных окружения Vercel.


## Цены и поддержка

Тарифы (в рублях, оплата криптой по курсу) задаются в `lib/plans.ts`: 30 дней — 100, 90 дней — 300, навсегда — 500.

Поддержка: клиенты пишут на `/support`, получают секретную ссылку на переписку. Отвечаете вы в `/admin` на вкладке «Поддержка» (красный счётчик показывает, сколько обращений ждут ответа).
